# Kəşfiyyat sənədi — qurma, yazma, təqdim

Bu skill sənədin **məntiqi quruluşunu, tonunu və etibar memarlığını** təyin edir. Dizayn üçün `artifact-design`, qrafiklər üçün `dataviz` yüklənir; nəticəyə çatmaq və onu sınamaq üçün `kesfiyyat-tradecraft`. Bu skill isə sənədi **yazır**.

## 0 · İlk qərar: kimə və hansı suala
Yazmağa başlamazdan əvvəl özün üçün bir cümlə yaz:
> Bu sənəd **[KİMƏ]** üçündür və **[HANSI SUALA]** cavab verir ki, **[HANSI QƏRARI]** verə bilsin.

Bunu yazmadan başlasan, nəticə data dump olur. **Qırmızı bayraq:** sənəd «biz nə ölçdük» ardıcıllığı ilə düzülübsə, auditoriya sualı verilməyib.

## 1 · Quruluş — QİYMƏTLƏNDİRMƏ ƏVVƏLDƏ (BLUF)
Kəşfiyyat yazısı akademik yazını tərsinə çevirir: nəticə sonda deyil, əvvəldə.
```
1. XÜLASƏ (BLUF)       — əsas analitik mesaj, 1–3 cümlə. «So what?»-un cavabı.
2. TƏSİR               — oxucu üçün nə deməkdir, nəyi dəyişir.
3. ƏSAS QİYMƏTLƏNDİRMƏLƏR — 3–7 ədəd, hər biri etibar dərəcəsi ilə.
4. HADİSƏLƏRİN GEDİŞATI — nə baş verdi: adlar, yerlər, tarixlər, insanlar.
5. DAYAQ               — hər qiymətləndirmənin sübutu ONUN ALTINDA (ayrı bölmə deyil).
6. YOXLANILMIŞ ALTERNATİVLƏR — rədd edilmiş izahlar və niyə rədd edildi.
7. MƏLUMAT BOŞLUQLARI  — ölçülə bilməyənlər, adla.
8. TƏKLİFLƏR / GÖSTƏRİCİLƏR — nə edilməli; hansı əlamət görünsə qiymətləndirmə dəyişər.
9. ƏLAVƏLƏR            — metodologiya, mənbə qiymətləndirməsi, audit izi.
```

### Registr qaydası — «HÖKM» sözü İŞLƏDİLMİR
Kəşfiyyat hökm vermir, **qiymətləndirir**. Hökmü qərar verən şəxs verir. «Hökm» Azərbaycan dilində məhkəmə registridir və səlahiyyət həddini pozur. İşlətmə → əvəzinə: ~~hökm~~ → **xülasə/qiymətləndirmə/nəticə**; ~~mühakimə~~ → **qiymətləndirmə**; ~~bu hökmü nə çevirər~~ → **bu qiymətləndirməni nə dəyişər**. Eyni prinsip təkliflərə aiddir: variant və onun qiyməti təqdim olunur, qərar verilmir.

**Hər abzas qiymətləndirmə ilə başlayır, sübutla davam edir** (topic sentence = qiymətləndirmə). Sübutla başlayıb nəticə ilə bitən abzas akademik yazıdır.

**İki yarı qaydası:** «süjet» və «sübut» bölmələri ayrı yarılarda olmamalıdır. Hər cədvəl aid olduğu qiymətləndirmənin altında dayanır — oxucudan onları öz başında birləşdirməyi tələb etmək ən tez-tez rast gəlinən struktur qüsurdur.

## 2 · Ton və üslub — rəsmi-işgüzar
- **Təsdiq cümləsi, hedge deyil.** Şübhə dərəcə ilə ifadə olunur, hər cümləyə «ola bilər / görünür ki» yapışdırmaqla yox.
- **Aktiv növ aktyor göstəriləndə:** «Hesablar yaradılmışdır» → «X şəbəkəsi 84 hesab yaratmışdır». Məchul növ yalnız nəticə əhəmiyyətli olanda: «aşkar edilmişdir».
- **Nəqli keçmiş zaman** (-mışdır/-mişdir): «aşkar edilmişdir», «çatmışdır». Sadə keçmiş («tapdı») publisistik üslubdur, işlənmir.
- **Çətin qiymətləndirmədən qaçma** (ICD 203): qiymətləndirmə verməməklə özünü qorumaq qüsurdur.
- **Metafora yolverilməzdir** — yerinə ölçülən göstərici. Rəqəm: onluq ayırıcı vergül (7,2), minlik boşluq (871 238).

### Qadağan olunmuş kalkalar → düzgün qarşılıq
| ❌ kalka | ✅ qarşılıq |
|---|---|
| çəki mərkəzi | əsas hissə, üstünlük təşkil edən seqment |
| səbəb zənciri | səbəb-nəticə əlaqəsi |
| aşağı/yuxarı axın | sonrakı / əvvəlki mərhələ |
| imza (bot imzası) | əlamət, fəaliyyət əlamətləri |
| qat | seqment, təbəqə, istiqamət |
| indikator | göstərici, əlamət |
| sürücü (driver) | təşəbbüskar, hərəkətverici qüvvə |
| pik | ən yüksək hədd |
| təmiz / çirkli data | düzgün / qüsurlu məlumat |

Danışıq dili çıxarılır: «işimiz var» → **söhbət … gedir**; «ona görə» → **bu səbəbdən**; «çıxdı, oldu» → **aşkar edilmişdir**.

### Bölmə adları — rəsmi variant
Hökm → **Xülasə**; Yeddi mühakimə → **Əsas qiymətləndirmələr**; Hadisə → **Hadisələrin gedişatı**; Alternativlər → **Yoxlanılmış alternativ izahlar**; Nə bilmirik → **Məlumat boşluqları**; Tövsiyə → **Təkliflər və müşahidə göstəriciləri**; Əlavə → **Əlavələr**.

## 3 · Etibar memarlığı — ƏN VACİB BÖLMƏ
**Ehtimal ilə etibar iki AYRI şeydir və bir cümlədə qarışdırılmır** (ICD 203).
- **Ehtimal** = hadisənin baş verməsi/iddianın doğru olması şansı.
- **Etibar** = o qiymətləndirmənin altındakı əsasın möhkəmliyi.

«Yüksək etibarla çox güman ki…» **qadağandır** — ikisi bir cümlədə olmaz.

**Ehtimal leksikonu (bir sıra seç, qarışdırma):** ehtimal yoxdur (~01–05%) · çox az ehtimal (05–20%) · az ehtimal (20–45%) · təqribən bərabər şans (45–55%) · ehtimallı (55–80%) · çox ehtimallı (80–95%) · tam əminliyə yaxın (95–99%).

**Etibar dərəcəsi (PHIA): Yüksək / Orta / Aşağı**, üç meyarla əsaslandırılır: (1) informasiya bazası — mənbə sayı, keyfiyyət, müstəqillik; (2) analitik sərtlik — neçə müstəqil üsul, nəzarət qrupu; (3) mövzunun dəyişkənliyi. Hər qiymətləndirmənin yanında **nə üçün o dərəcə** bir cümlə ilə.

**Praktiki dərəcələmə — sənəddə görünən etiket:**
```
A  çoxlu müstəqil üsul + böyük n + təkrarlanıb  → qeyd-şərtsiz təsdiq cümləsi
B  bir üsul, həddi bilinir                      → istiqamət verilir, dəqiq rəqəm yox
C  göstərici var, nəticə çıxarılmır             → TƏKLİFƏ GİRMİR, və bunu sənəd deyir
–  ölçülə bilməyən                              → adla göstərilir, susmaqla yox
```
Fərqləndirilməmiş şübhə sənədi olduğundan zəif göstərir. Qeydləri gizlətmək yox, **dərəcələmək** həlldir.

## 4 · Tapıntı necə qabardılır
1. **Gözlənilməyəni ön plana çıxar.** Gözlənilən tapıntı xəbər deyil.
2. **Rəqəm tək qalmır — müqayisə bazası ilə:** «871 238» yox, «871 238 ↔ 132 736 = 6,6×».
3. **Vahid müqayisə olunan olmalıdır;** platformalararası ♥ müqayisə edilmir, seçim səbəbi ilə deyilir.
4. **Təkzib tapıntıdır:** «X yoxdur» — doğru axtarılıbsa — müsbət tapıntı qədər dəyərlidir.
5. **Nəticəni oxucuya buraxma:** «Bu rəqəmlər göstərir ki…» cümləsini sən yazırsan.

## 5 · İnsan olmalıdır
SOCMINT/şəbəkə təhlilində ən tez-tez qüsur: sənədin vahidləri hesab adı və metrik olur, hadisənin **insanları** yoxa çıxır. Qərar verən şəxs qərarı insanlar haqqında verir. Hər sənəddə: adlar, yerlər, tarixlər, sənədlər, sitatlar. Sitat **göstərilir** ki oxucu özü yoxlaya bilsin; mövqe/niyyət kimi mülahizə tələb edən oxunuş **analitikin qərarı** kimi açıq etiketlənir.

## 6 · Görülmüş iş və vizuallaşdırma
Görülmüş işi analitiki qəhrəman edən şəkildə yazma. İş **sorğunun predmeti bölməsində** bir dəfə, metodologiya **əlavədə**, əhəmiyyət **təsir cümləsində**, hər qiymətləndirmənin dayağı **onun altında** bir-iki sətir. **Ölçü nisbəti:** qeyd/xəbərdarlıq qutuları qrafiklərdən çox olarsa, sənəd metodologiya auditinə çevrilib — düzəlt.

Arqumenti daşıyan 2–4 vizual (cədvəl yığını deyil): **zaman xətti** (səbəb-nəticə ardıcıllığı), **seqment/çəki diaqramı**, **aktyor-axın xəritəsi** (istiqamət oxları ilə), **etibar matrisi**. Qalanı cədvəl ola bilər.

## 7 · Təslim etməzdən əvvəl — minimal qapı
Bunlar olmasa sənəd hazır deyil:
- [ ] Xülasə birinci ekranda, bir cümlə ilə
- [ ] Hər əsas qiymətləndirmənin etibar dərəcəsi var
- [ ] Ehtimal və etibar bir cümlədə qarışmır
- [ ] Rədd edilmiş alternativlər və niyə rədd edildiyi var
- [ ] «Məlumat boşluqları» bölməsi adla mövcuddur
- [ ] Hər qiymətləndirmənin dayağı onun yanında, ayrı yarıda deyil
- [ ] Hadisədə insan var — ad, yer, tarix, sitat
- [ ] C dərəcəli heç bir tapıntı təklifə girmir
- [ ] Qeyd qutuları qrafiklərdən çox deyil
- [ ] Kalka və danışıq dili yoxdur (§2 cədvəli)
- [ ] Qiymətləndirməni dəyişəcək göstəricilər sadalanıb
