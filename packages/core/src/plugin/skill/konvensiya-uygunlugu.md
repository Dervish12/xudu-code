# Konvensiya uyğunluğu

Yazdığın kod ətrafdakı koddan seçilməməlidir.

## Uyğunlaş
- **Adlandırma**: mövcud dəyişən/funksiya üslubu (camelCase/snake_case), qısaltmalar.
- **Şərh sıxlığı**: ətraf az şərhlidirsə, şərh yağdırma; çoxdursa, izah ver.
- **İdiom**: layihənin istifadə etdiyi kitabxana/naxış — yeni kitabxana gətirmə, mövcudundan istifadə et.
- **Struktur**: qovluq/fayl yerləşməsi, import sırası, formatlaşdırma (mövcud linter/formatter-a tabe).

## Əvvəl
Yazmazdan əvvəl qonşu 1-2 oxşar faylı oxu və onların üslubunu götür. Öz üslubunu dayatma.
